# HSE Provider

Responsive implementation of the CSMS Overview design in Figma.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

- `/` — CSMS Overview
- `/csms` — CSMS Overview

The current implementation covers the English desktop and mobile designs. The layout is structured so Vietnamese content can be added without duplicating the page.
